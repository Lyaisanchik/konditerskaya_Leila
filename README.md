# Цветущая кондитерская

Сайт для продажи сладких съедобных цветов и бутонов в Нефтекамске.

## Как открыть

Откройте файл `index.html` в браузере (двойной клик) или через Live Server.

## Структура

| Раздел | Адрес |
|--------|--------|
| Главная | `#/` |
| Каталог | `#/catalog` |
| Карточка товара | `#/product/p1` |
| Корзина | `#/cart` |
| Доставка | `#/delivery` |
| Политика конфиденциальности | `#/privacy` |
| Публичная оферта | `#/offer` |
| Админка | `#/admin` |

## Админка

- Пароль по умолчанию: `leila2026` (меняется в `js/data.js` → `ADMIN_PASSWORD`)
- Заявки с корзины попадают во вкладку «Заявки»
- Товары можно добавлять, редактировать и удалять (хранятся в `localStorage` браузера)

## Технологии

Чистый HTML + CSS + JavaScript, без сборки и сервера. Данные каталога и заказов — в `localStorage`.
